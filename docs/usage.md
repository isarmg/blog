# 发布和管理内容

先完成[首次运行](getting-started.md)，通过站点的 `/admin` 登录。从顶部菜单直接进入对应管理页面；顶部还提供语言和明暗主题切换。

日期和时间统一使用 UTC，包括文章进展的时间输入。页面会标明 UTC，不随浏览器所在地时区切换。

## 发布一篇文章

1. 先在“分类管理”创建分类，再在“标签管理”为这个分类创建标签。每篇文章必须选一个分类和一个属于它的标签；已有合适的可以直接用。
2. 在“文章管理”点右上方的 **+（新增文章）**，填写标题、分类、标签和 Markdown 正文。用“预览正文”检查排版；封面可填地址或直接上传。“插入正文图片”会把图片追加到正文末尾，可再移动到需要的位置。
3. 核对“公开访问”“推荐”“允许评论”，再点“保存文章”。新建文章默认公开并允许评论。成功后回到列表，核对标题、编号和“公开”或“加密”状态。
4. 用未登录的窗口打开 `/article/编号`（例如编号为 12 就打开 `/article/12`），检查读者实际看到的正文、图片或密码提示，再分享链接。

**关闭“公开访问”不是存为隐藏草稿。** 首次加密时须设置文章访问密码（12–1024 个 UTF-8 字节，不含 ASCII 控制字符）。前台仍会列出标题，也能按标题搜索；不显示正文摘要，读者不能按正文内容搜索。可填密码提示，但不要把密码写在提示里。读者输入正确密码才能看正文。编辑已加密文章时密码留空会保留原密码；重新勾选“公开访问”并保存会移除密码。

文章保存后，在“文章管理”点“编辑”可维护“最新进展”。时间按 UTC 输入；新增留空取当前时间，编辑留空保留原时间。进展列表可翻页，翻页或重试读取不会清空正在编辑的进展。加密文章即使已解锁，读者页面也不显示“最新进展”或评论区。

新建文章、随笔或进展时，如提示原提交等待确认，先留在当前编辑页，点对应的确认按钮（例如“确认原文章提交”）。原提交确认后再保存较新的修改；不要刷新或另开页面重新发布。若已离开，先检查列表是否有这条记录。

### 整理分类和标签

- 已被文章使用的标签可以改名。要移动或删除它，先编辑引用它的文章，改选其他标签并保存。
- 删除分类会一并删除它的标签和使用它的首页栏目。先把该分类的文章改到其他分类并选好标签；如果首页启用的栏目都使用它，先启用并保存一个不使用它的栏目。

## 在文章中放置视频

文章的“视频地址”设置正文上方的视频，也可直接选择文件上传。正文中的视频可插入多个：先把光标放在目标位置，再填写正文视频地址并插入，或选择上传正文视频。上传完成后保存文章，读者才会看到修改。

光标或部分选区位于代码、链接、表格等格式内部时，视频会放在完整内容块之后，保留原有内容。未结束的格式会提示先补全或移动光标，不改写正文；若文件已经上传，可在文件管理中找到它。

支持 MP4、WebM 文件的 HTTP(S) 直链、站内媒体路径，以及 B 站和 YouTube 视频链接。B 站使用包含 BV 或 av 编号的完整地址，支持分 P；`b23.tv` 等短链接需先打开再复制完整视频地址。YouTube 支持观看页、`youtu.be`、Shorts 和官方嵌入地址；平台链接会转换为官方播放器。文件上传上限为每个 50 MiB，直链播放取决于浏览器是否支持视频编码。

也可在 Markdown 中手动写入独立的 `video` 代码块，每块只放一个地址。将下例中的地址换成自己的视频直链或上传后得到的完整 `/media/…` 路径：

````markdown
```video
https://media.example.org/demo.webm
```
````

预览和公开页面使用相同的视频渲染规则。普通视频链接仍显示为链接，原始 `<video>`、`iframe` 和其它 HTML 仍显示为文字。不支持的 `video` 代码块保留为代码，方便修正地址。删除仍被文章引用的本站视频会被阻止，先从文章中移除引用并保存，再删除文件。

## 上传与维护媒体

“文件管理”可上传 PNG、JPEG、GIF、WebP 图片，单个不超过 10 MiB。复制上传结果中的地址，不要用原文件名拼路径。视频从文章编辑器或“网站设置”的百宝箱背景视频字段上传，接受 MP4、WebM，单个不超过 50 MiB。上传成功只表示文件已存入站点，还需保存对应文章或设置，页面才会引用它。

**媒体地址可直接访问，不受文章密码保护。** 不要上传仅限特定读者访问的文件。要删除媒体，先在引用它的文章、随笔或设置中移除引用并保存，再到“文件管理”确认删除。隐藏内容不等于移除引用；删除源文件也不会撤回浏览器或代理已缓存的副本。

在“内容资源”填写标题、选择类型，勾选“公开显示”后保存。按前台用途填写地址：

| 类型 | 怎么填 |
| --- | --- |
| 照片 | 把上传得到的 `/media/…` 路径或外部图片地址填入“图片地址”。相册用它显示缩略图和大图；只填“目标地址”不会显示照片。 |
| 音乐与趣味 | 把可播放的 HTTP(S) 音频直链填入“目标地址”，“图片地址”可作封面。目标地址留空的条目不会进入播放列表。 |
| 友链、收藏 | “目标地址”填要跳转的 HTTP(S) 网页，“图片地址”可作封面。待审核友链在列表点“审核通过”。 |

## 维护随笔和信笺

在顶部“随笔管理”新增或编辑正文，可上传配图并设置“公开可见”。公开随笔同时显示在随笔页和“家”的日常记录；可在列表中隐藏或删除。取消编辑可放弃未保存的修改，分页或读取重试会保留当前编辑内容。

在“信笺管理”填写收信人、署名与正文，勾选“公开显示”后保存。前台信笺读取实际保存的内容；隐藏后显示未发布状态，保存失败会保留当前输入。

## 调整首页和恋爱笔记

在“首页栏目”选择“最新文章”“推荐文章”或“指定分类”作为内容来源，用上下移动按钮排序，点“保存栏目”后刷新首页。推荐栏目只显示勾选了“推荐”的文章；最多可配置 12 个栏目，至少启用一个。“网站设置”中的站长显示名用于文章与随笔署名，不改变管理员登录名。

在“恋爱笔记”维护唯一一份“家”的资料：人物、简介、起始时间和倒计时。访客可浏览公开的相册、日常记录和发送祝福，不能创建资料。取消资料的“公开显示”不会同时隐藏单独发布的随笔、照片或信笺；要隐藏它们，分别到对应管理页修改。

## 配置头像、背景和横幅

在“网站设置”的外观区域配置站点标志、站长头像、首页背景，以及时间轴、随笔和留言板的背景。恋爱笔记的信笺背景与三个栏目封面也在此设置；“家”页主背景和人物头像仍在“恋爱笔记”中维护。

图片和视频可填写站内媒体地址或 HTTP(S) 地址，也可直接选择文件上传。移除某项地址后保存，即可清除该位置的媒体。站点不附带默认照片、头像或视频；没有配置时，页面使用文字、图标和底色，不请求预置媒体文件。

百宝箱横幅由收藏夹、音乐和友人帐共用。配置背景图可显示静态横幅；配置视频可显示静音循环视频，背景图同时作为视频封面。清空视频地址后保留背景图即可恢复静态横幅。

## 管理互动内容

留言板（`/message`）上方的弹幕和下方的评论是两种不同的提交，访客都无需登录：

| 访客在哪里提交 | 管理员在哪里处理 | 没有收到成功提示时 |
| --- | --- | --- |
| 文章评论、祝福墙、留言板下方的评论及回复 | “评论管理”；删除顶层评论会同时删除该楼层全部回复 | 在原标签页点“确认原提交”。同一标签页刷新后仍可确认，不必新发一条 |
| 留言板上方的“发射”弹幕（纯文字，最多 60 字） | “留言板管理” | 没有“确认原提交”功能；先刷新查看弹幕，直接重发可能重复 |

文章仅在公开、无访问密码且勾选“允许评论”时接受访客评论。更多重试规则见[数据与请求约定](contracts.md)。

## 修改管理员账号

1. 从后台右上角头像打开账号设置。
2. 填写用户名和当前密码；新密码留空则保留现有密码，修改密码时填写两次相同的新密码。
3. 保存成功后，使用新的账号信息重新登录。

用户名使用 3–64 个 ASCII 字符，以字母或数字开头和结尾，中间可包含字母、数字、`.`、`_`、`-`，保存时统一为小写。管理员密码要求 12–1024 个 UTF-8 字节，不能包含 ASCII 控制字符。

保存时先验证当前密码，再更新账号并撤销已有会话。如果服务器拒绝修改，请重新输入密码；离开账号设置也会清除密码输入。页面的语言与明暗主题选择在刷新、登录和退出后保持。忘记管理员密码时，按[运行与排障](operations.md#恢复管理员访问)进行离线重置。

如页面加载或保存失败，保留错误提示及请求 ID，按[运行与排障](operations.md)检查。
